# How screc is licensed

The source is under the [MIT License](LICENSE) — clone it, build it,
change it, ship your fork.

Binaries distributed through the Mac App Store are covered by Apple's standard
End User License Agreement instead, and are sold for a small fee. Buying one is
never required — it exists for people who would rather not clone a repository
and build from source.

If you improve screc, sending the change back upstream as a pull request is
appreciated. That is a request, not a condition of the license above.
